# Grab Your Torch brand assets

The Victory Flame identity is the visual authority for the website. This
directory owns the supplied brand package; `public/` owns only what the site
serves. Nothing under `docs/brand` is fetched by the built app.

`docs/brand/brand-guidelines.md` is the normative identity reference (palette,
typography, clear space, minimum sizes, construction rules). Read it before
placing a logo.

## Roles

| Role           | Location                                                                                                            | Meaning                                                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **source**     | `docs/brand/source/`                                                                                                | The untouched vector and raster deliverables exactly as supplied. Edit these only when the brand changes; rerun the generator afterwards. |
| **reference**  | `docs/brand/reference/`                                                                                             | Human-readable identity references for design review. Never shipped.                                                                      |
| **provenance** | `docs/brand/provenance/`                                                                                            | How the identity was produced. Never shipped.                                                                                             |
| **archive**    | `docs/brand/archive/`                                                                                               | The original delivery ZIP, kept intact for audit. Never shipped.                                                                          |
| **production** | `public/brand/`, `public/favicon*.{svg,png}`, `public/apple-touch-icon.png`, `public/og-image.png`, `public/icons/` | Generated by `yarn tsx scripts/generate-web-assets.ts`. Do not hand-edit; regenerate.                                                     |

## Generating the shipping assets

```sh
yarn tsx scripts/generate-web-assets.ts          # regenerate and validate
yarn tsx scripts/generate-web-assets.ts --check  # validate the committed outputs
```

The generator:

1. **Outlines the wordmark.** The supplied lockups set "Grab Your Torch" as
   live SVG `<text>` in Space Grotesk. Fonts do not load inside `<img>`-embedded
   SVGs, so a visitor without Space Grotesk installed would silently see Arial.
   Shipping lockups have every glyph converted to a path using the same
   version-pinned `@fontsource-variable/space-grotesk` and
   `@fontsource-variable/inter` files the app bundles (Latin, normal style,
   weight axis). The brand guideline's "ExtraBold Italic (800)" for _Torch_ is
   reproduced as weight 700 (the top of Space Grotesk's weight axis) with a
   14 degree synthetic oblique, which is exactly what a browser renders for the
   source file when the font is present. Outlined files carry a provenance
   comment naming their source.
2. **Rasterizes** PNG exports at the supplied dimensions, the pixel-aligned
   16 px and 32 px favicons, the Apple touch icon (flattened onto Night Navy so
   iOS never shows black corners), the 192 px and maskable 512 px manifest
   icons, and the 1200x630 Open Graph image.
3. **Writes `public/site.webmanifest`** from `WEB_MANIFEST` in
   `scripts/lib/brand-assets.ts`, the single definition the tests check.
4. **Validates** that every expected file exists at its exact size, that no
   shipping SVG contains `<text>`, gradients, filters, or raster effects, and
   that `index.html` and the manifest reference only files that exist.

`scripts/__tests__/generate-web-assets.test.ts` runs the same validation in
CI, so a stale or hand-edited asset fails the build.

Note on the supplied PNGs: they were rendered with a fallback sans-serif
(Space Grotesk was not installed on the rendering machine), so the regenerated
rasters in `public/` are the first ones that show the intended wordmark. The
supplied PNGs are kept in `source/` as the delivery record.

## Using the logos in the app

- Prefer `src/components/Brand` components over raw `<img>` tags; they pick
  the correct variant for the color scheme and enforce minimum sizes.
- Never recolor the trophy cutout, add strokes, shadows, or gradients, or
  shrink the full emblem below 40 px. Below that, use the favicon artwork.
- Keep 1x handle width of clear space around the emblem and 1.5x around
  lockups (see the guidelines for the definition of x).
- Brand colors are a system, not a replacement for semantic colors: scoring
  categories, success, warning, and danger keep their own palette.
